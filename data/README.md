# Data — 2016 Seattle Building Energy Benchmarking

## Source & license

**2016 Building Energy Benchmarking** — City of Seattle Open Data
https://data.seattle.gov/dataset/2016-Building-Energy-Benchmarking/2bpz-gwpy

**License: open data (City of Seattle Open Data Program).** Free to use with
attribution. The city publishes this dataset for transparency on building
energy performance.

## File

`2016_Building_Energy_Benchmarking.csv` — one row per building, 46 columns
(physical characteristics + measured energy/emissions). ~3,376 buildings; the
pipeline keeps the ~1,651 non-residential ones after cleaning.

The CSV is small (~1 MB) so it is included in the repo for reproducibility.
